\section{Source Code and Reproduction}
\subsection{Source Code Organization}
The source code is located under \code{pq-test/} in the project. The main files
relevant to this report are listed below.
\begin{table}[H]\centering\small
\caption{Main source files and their roles}
\begin{tabularx}{\linewidth}{lX}\toprule
File & Role\\\midrule
\code{csr-graph.hpp}, \code{dimacs-parser.hpp} & Shared graph representation and file parsing\\
\code{general-dijkstra.hpp} & Shared main Dijkstra loop\\
\code{heap-adaptor.hpp} & Timestamp interface, standard-library adaptor, and PBDS adaptors\\
\code{binary-heap.hpp}, \code{segment-tree-heap.hpp} & Binary heap and segment-tree heap\\
\code{fibonacci-heap.hpp}, \code{radix-heap.hpp} & Fibonacci heap and radix heap\\
\code{general-bellman-ford.hpp} & Two label-correcting algorithms\\
\code{dij-bench-v2.cpp} & Random-graph parameter sweep\\
\code{dij-bench-complexity.cpp} & Fixed-density complexity experiments\\
\code{dij-bench-dimacs.cpp} & Road-network query benchmark\\\bottomrule
\end{tabularx}\end{table}
